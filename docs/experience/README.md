# TSTA Reserve｜予約からキャンセル待ちまでの体験デモ Ver.0.11（試作）

本番TSTA Reserveから **予約側 `index.html` / 管理者側 `admin.html` の画面構成・主要なCSS・TSTAアイコンを再利用**した採用向けの模擬操作版。

- デモ専用の架空の名前・架空の予約を使います。実在人物のデータは含まれません。
- Firebase・認証・Cloud Functions・外部API・Web Push・チャットの送信とは**接続しません**。
- 画面の一部（予約・参加者管理の中心）を再現したプロトタイプです。本番の全機能を移植したものではありません。
- 画面の案内は、画面右上に固定されるオレンジ色のツールチップ方式。次に押す位置を強調して自動スクロールします。管理者の参加取消は一覧にも説明を表示します。いつでも案内をOFF、最初からやり直すことができます。
- キャンセル待ちから繰り上がった場合の模擬通知は、**画面中央の確認必須ダイアログ**です。背景を暗くし、確認ボタン以外は操作できません。
- データは同じタブの `sessionStorage` に一時保存。ページを移動しても体験を引き継ぎ、別タブには共有されません。

## 使い方

リポジトリのルートで以下を実行し、 `http://localhost:8000/experience/` を開きます。

```bash
python -m http.server 8000
```

1. 予約画面で架空のプロフィールを登録
2. 初心者・ブランク有(B)を選び、緑の開催日で予約
3. 予約側の予約一覧で予約完了を確認した後、管理者画面へ移動。管理者のカレンダーで日付を選び、「参加者一覧」に自分の名前があることをオレンジ枠で確認してから進む
4. 管理者画面から予約側へ戻り、経験者(A)を選び、満席（濃い灰色）の日にキャンセル待ち登録
5. 管理者側で「経験者(A)」一覧の赤い「参加取消」を押して、サンプル参加者を1人取り消す
6. 予約側に戻り、画面内の模擬通知で繰り上がり枠の予約を確定

## Ver.0.3の主な修正

- 指示が画面から消える場合の表示ロジックを改修。ガイドONなら必ず表示し、強調箇所へスクロールします。
- 最初の参加予約は**初心者(B) → 次回開催日 →「予約する」**の順で誘導します。経験者を選んだ場合は理由を案内して再選択できます。
- 初心者(B)でも2回目の開催日を架空参加者4名で満席にし、濃い灰色で表示します。
- 2周目のキャンセル待ちは**経験者(A) → 満席の日 → キャンセル待ち**の順で案内します。
- デモ用の一時データキーを更新したため、古いVer.0.2の途中状態は引き継ぎません。
- 開催日は日本時間を基準に次の土曜日と翌週土曜日を自動生成します。

## 制約

「通知が届く」は、**Webプッシュを再現しているのではなく、同一タブで確認できる模擬通知**です。先着順競合制御、ネットワーク切断時の同期、実際の認証・課金・個人情報管理などは、デモで表現していません。

元の画面構成の参考：`TSTA-app2_20261106-201052.zip` の `public_plain.refactor/index.html`、`admin.html`、および対応CSS。画面構成・スタイルは原版を元にしていますが、説明用の一部項目を簡略化しています。

## Ver.0.5: 予約結果の確認

初心者(B)で予約を完了すると、ページ上部の「あなたの予約一覧」に自動スクロールします。架空の予約が表示されたことを確認し、「確認できた！ 次へ進む」を押すと、管理者画面への案内が表示されます。操作ガイド有効時は確認を飛ばして管理者画面へ移動できません。

【Ver.0.6追加】管理者の最初の開催日のカレンダー選択後は、参加者一覧と予約者の氏名をオレンジ枠で強調します。必ずその場で名前を確認し、「確認した！ 次へ進む」を押してからキャンセル待ちへ進みます。ほかの機能は任意のボタンから概要を紹介します（本番接続なし）。

## Ver.0.8: 追加したガイド操作

- 満席日の体験では、経験者(A)の選択肢をプルダウンの直下にオレンジで強調して表示します。OSのプルダウン描画には依存しません。
- キャンセル待ち通知を確定してもすぐに完了扱いにせず、予約側の予約一覧→管理者側の経験者参加者一覧で反映を確かめます。
- 管理者一覧の本人確認ボタンで基本体験完了。その後「ほかの機能も見てみる」に誘導し、試合ボード・戦績表等を任意で紹介します。
- すべて架空データをブラウザのセッション内で扱います。本番Firebaseには接続しません。

## Ver.0.10: 状態の強調とガイド位置の統一

- 管理者のキャンセル待ち一覧で、本人の行をオレンジ色で強調。状態を「⏳ キャンセル待ち登録中」「🔔 繰り上がり案内中」と目立つバッジで表示します。
- 参加取消後（⑭の案内）に、「繰り上がり案内中」の本人の行と「予約側へ戻って通知を確認」ボタンをそれぞれ強調します。
- 操作ガイドの吹き出しは、PCでもスマートフォンでも右上に固定。以前のように途中で右下や左下へ移動しません。
