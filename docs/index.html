JavaScript / Firebase を活用した実運用システムの紹介

TSTA Reserve
予約管理を、体験して理解する。

ソフトテニス団体の実運用で見つかった課題から設計・開発した予約管理システムです。参加者の予約、管理者による確認、キャンセル待ちと繰り上がりを、架空データでひと通り体験できます。

🎾 体験デモを開始する技術解説・ソースコードを見る

体験できること

📅 予約者の体験

区分と日付を選んで予約。予約内容が一覧に表示されることを確認します。

👥 管理者の体験

管理画面で日付を選び、予約した本人の名前を確認します。予約側と管理側の情報連携を体験できます。

🔔 キャンセル待ち

満席日の登録、他の参加者の取消、模擬通知と繰り上がり予約、その後の管理者側への反映まで確認します。

体験の進め方

1. 「体験デモを開始する」をクリック
2. 右上の操作ガイドに従い、オレンジ色の場所を順番に操作
3. 予約者画面と管理者画面を行き来し、最後まで体験
4. 体験完了後は、ほかの機能紹介も自由に閲覧できます

技術と工夫

JavaScript (ES Modules) を中心に、業務の流れ全体を見通した画面設計と、同名・別人の誤統合を防ぐ人物識別などを実装しています。GitHubには、代表的なドメインロジックと回帰テストも公開しています。

🔒 安全な模擬環境：このデモは本番のFirebase、会員情報、通知システムへ接続しません。入力した架空のデータはブラウザの同じタブ内の一時領域に保存されます。テスト用の架空名でお試しください。通知は画面内の模擬表示です。体験版は本番機能をすべて実装したものではありません。
